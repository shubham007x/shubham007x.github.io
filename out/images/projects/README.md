# Project Images

Place your project screenshots here!

## How to use:

1. **Add your images** to this folder (`public/images/projects/`)
2. **Name them** descriptively, for example:
   - `quickshow.jpg`
   - `car-ai-dashboard.jpg`
   - `teleworld.jpg`
   - `finance-analysis.jpg`
   - `alcazar.jpg`

3. **Update the image paths** in `app/components/Projects.tsx`:
   - Change from: `"https://images.unsplash.com/..."`
   - To: `"/images/projects/your-image-name.jpg"`

## Supported formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

## Recommended image size:
- Width: 800-1200px
- Height: 600-800px
- Aspect ratio: 4:3 or 16:9

## Example:
```typescript
image: "/images/projects/quickshow.jpg"
```
